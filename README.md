# Divika — Cerdas static template

Local static HTML mirror of the Holyline Cerdas template kit.

## Run locally

```bash
npm start
```

Open **http://127.0.0.1:4765/** (redirects to home) or:

**http://127.0.0.1:4765/cerdas/template-kit/home/**

Home file on disk: `cerdas/template-kit/home/index.html`  
(Use `npm start` — pages need a local server because assets use root paths like `/cerdas/...`.)
